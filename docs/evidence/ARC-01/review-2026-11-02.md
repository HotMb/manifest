## `arc01_backend` — revue backend / plateforme

- **Mandat reçu :** vérifier en lecture seule si le serveur stdio actuel est compatible avec Secure MCP Tunnel, si une conversion de transport est requise, et lister les préconditions sans installer le tunnel ni lire de secret.
- **Contribution reçue :** la documentation officielle prévoit un lancement local MCP en stdio via `--mcp-command`; le `StdioServerTransport` existant peut donc être conservé. Il faut un client tunnel, un `tunnel_id`, une clé runtime protégée, les associations et permissions d'organisation/workspace, puis le contrôle `doctor` et un appel réel dans ChatGPT. La clé runtime du tunnel est distincte de l'identité utilisateur/OAuth de l'application. Aucun changement de transport ne se justifie au vu de cette tentative.
- **Indépendance de rôle :** agent backend séparé, revue en lecture seule ; aucun fichier, tunnel ou paramètre utilisateur n'a été modifié par cet agent.

## `arc01_design_review` — revue design / UX desktop

- **Mandat reçu :** comparer les voies desktop WebMCP et plugin local pour le déclenchement `/manifest`, le champ réactif, l'aperçu et `/validate`, en lecture seule.
- **Contribution reçue :** WebMCP signifie une page Manifest déjà ouverte dans le navigateur intégré ; ses outils sont découvrables après l'ouverture et l'enregistrement. Le champ de cette page peut relancer l'aperçu pendant la saisie, mais la disponibilité d'une réponse ChatGPT à chaque pause n'est pas garantie par le partage d'état. `/manifest` reste une intention/alias tant qu'une commande native n'est pas prouvée. `/validate` doit lire et figer la version réellement visible, confirmer l'approbation et rapporter cette révision sans faire croire que le code complet est déjà généré.
- **Recommandation reçue :** un spike Site Tools/WebMCP desktop réutilisant Snapshot/contrôleur, puis qualification dans le vrai hôte. Le plugin local reste conditionné à l'allowlist et à la preuve d'identité.
- **Indépendance de rôle :** agent design distinct, avis en lecture seule ; aucun composant ou document n'a été modifié par cet agent.
