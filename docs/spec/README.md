# Spécification de départ

Ces fichiers proviennent du cadrage version 1.0 du 1er novembre 2026, intégré au dépôt pour servir de référence à l'équipe. Les contrats structurels et exemples figurent dans contracts/. Les comportements et valeurs de l'éditeur sont maintenus à la racine dans [UX-CONTRACT.md](../../UX-CONTRACT.md) et [DESIGN.md](../../DESIGN.md).

Le [compte rendu du cadrage](VERIFICATION.md) est historique : il décrit les contrôles de ce dossier documentaire avant le bootstrap. Les preuves actuelles de développement sont enregistrées dans [docs/evidence](../evidence/BOOTSTRAP.md) et le [statut du projet](../STATUS.md). Ne pas confondre la validité des exemples avec l'exécution du produit.

Les évolutions approuvées du cadrage se font ici avec leur ticket et leurs impacts. Le dossier original hors dépôt reste une livraison d'archive ; l'équipe ne maintient pas deux spécifications en parallèle.
